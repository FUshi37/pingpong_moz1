## 共同基线

所有模型使用 7-D QVEL、measured q/dq 与持续积分的 q_ref、200 Hz 策略和 1 kHz RMP/MJX，
`recovered_rmp_rmpmd_v2`，固定对齐底座，6 s/1200 步回合，90 Hz 球观测。
实际球质量范围固定为 `[0.004,0.004] kg`；启动命令的 3.9--4.1 g 是质量证据准入范围，
不代表这些模型进行了质量 DR。RMP 输出延迟为 `[18,19,19,18,18,18,18] ms`，
q_ref 的七关节 error-horizon 均为 10 s，另有工作空间投影及关节限位。
原有 real11 1 ms 接触参数未因本次归档改变；V274 的反弹扰动是附加外力，不是重标定接触参数。

保存的 PPO 参数共同为 1024x128、minibatch 16384、4 epochs、LR 1.5e-5、gamma 0.9995、
lambda 0.99、clip 0.12、target KL 0.006、uniform BC 0.05。
V319 另保留历史策略 replay KL 系数 10，并要求每个 update 的全部 32 个 minibatch 生效。
这些数值只补充运行身份，不代替下面的逐关课程说明。

## 模型文件、网络结构与推理接口

六个 pickle 的顶层均保存 `params`、`opt`、`args`、`env_cfg`、模型维度、阶段身份和验证记录。
`params` 实际包含 `pi`、`v`、`log_std`，没有 teacher/residual 分支或循环网络。
部署 Actor 使用 `params['pi']`；`params['v']` 是训练用 Critic，`opt` 是 Adam 状态。
`stage_actor_anchor_reference_params` 等训练保留字段也不作为第二个部署 Actor 叠加执行。

| 模型 | Actor 网络 | Critic 网络 | Actor 输入语义 |
| --- | --- | --- | --- |
| V223 S15 | 72->256->256->7 | 393->256->256->1 | 72-D 位置历史；当前拍姿态观测有每回合偏差 |
| V224 S14 from V223 | 117->256->256->7 | 438->256->256->1 | 同一 72-D 前缀，加 45-D 因果上下文 |
| V224 S14 from V172 | 117->256->256->7 | 438->256->256->1 | 与上一行接口完全相同，模型权重和训练谱系独立 |
| V274 S9 | 72->256->256->7 | 398->256->256->1 | 72-D 位置历史；未加球位置 AR1 噪声 |
| V274 S11 | 72->256->256->7 | 398->256->256->1 | 同一布局；球位置采样包含 AR1 噪声 |
| V319 S17 | 72->256->256->7 | 393->256->256->1 | 72-D 位置历史；配合近侧位置/动量恢复课程 |

两层隐藏层使用 tanh，输出层是线性层。确定性推理为：

```text
h1 = tanh(obs @ W1 + b1)
h2 = tanh(h1  @ W2 + b2)
mu = h2 @ Wout + bout
```

输入使用 float32；批量接口为 `(N,72)` 或 `(N,117)`，Actor 原始输出为 `(N,7)`。
两种 Actor 的第一层权重分别为 `(72,256)` 和 `(117,256)`，第二层为 `(256,256)`，输出层为 `(256,7)`。
Critic 输出每个环境一个标量 value，不是动作或硬件命令。
训练另使用每关节一个、与状态无关的 `log_std[7]` 作高斯探索；确定性推理直接取 `mu`。
Actor 输出端没有 tanh，实际动作范围由后续 clip 限制。
输入构造没有运行均值/方差标准化，也没有另存 obs RMS；须保持下面的单位与显式缩放。

## 72-D Actor 输入的精确字段顺序

四个 72-D 模型及两个 V224 的前 72 维都使用
`fixed_plane_v149_position_only_contiguous_72d` 布局。
索引采用 Python 左闭右开切片；所有七关节块和输出的顺序固定为
`[RightArm-0, RightArm-1, RightArm-2, RightArm-3, RightArm-4, RightArm-5, RightArm-6]`。

| 切片 | 维数 | 字段及单位/缩放 |
| --- | --- | --- |
| `0:7` | 7 | 当前 measured q，rad |
| `7:14` | 7 | 当前 measured dq，rad/s |
| `14:21` | 7 | 持续策略参考 `q_ref - q_measured`，rad；来自 `state.arm_cmd_q` |
| `21:28` | 7 | 上一 tick 实际投影后回填的归一化动作；不是未经限幅的网络输出 |
| `28:52` | 24 | 八个连续 200 Hz tick 的持有球位置，按 XYZ 展平，最新到最旧，m |
| `52:55` | 3 | 当前 FK racket site XYZ，m；不是碰撞 geom 表面点 |
| `55:61` | 6 | 当前观测拍姿态 rotation6D，顺序为旋转矩阵第0列XYZ、第1列XYZ |
| `61:69` | 8 | 与八个球位置槽对应的源样本 age：`clip(age_seconds/0.25,0,1)` |
| `69:71` | 2 | `state.racket_anchor[:2]`，即训练 episode target XY，m |
| `71:72` | 1 | `fixed_contact_ball_observed` 的 float32 0/1 标志 |

球位置、racket site 和 target XY 使用训练仿真 world 对应的标定坐标，不能直接填入相机坐标或球减拍相对坐标。
球位置的几何对象是球心；racket site 与拍面表面的定义不能混用。
rotation6D 使用旋转矩阵前两列，不能换成前两行、欧拉角或四元数。
V223 和 V224 的姿态观测为 `R_FK @ Exp(local_XY_bias)`；V274 和 V319 没有这项姿态观测偏差。

八个历史槽对应 0/5/10/15/20/25/30/35 ms 的策略 tick。
相机以 90 Hz 产生新采样，两个新采样之间持有位置，所以八个槽不等于八个不同相机帧。
这里的 age 来自直接持有样本的采样时间；不能用“预测到当前时刻”的位置再配一个旧原始样本 age。
每个历史 age 是该历史 tick 当时记录的年龄，随槽一起移动，不把所有旧槽统一改算为当前查询时刻的年龄。
保存配置中 `ball_obs_age_tracks_stale=False` 并不关闭这个 72-D 分支的 age 槽，后者显式读取连续历史 age。
最后一维也不能自行替换成 predictor-valid、击球有效标志或相机可见性标志。

Actor 没有显式球速、未来触球位置、hit_count、阶段编号、目标 apex、物理真值、DR latent 或 RMP 内部状态输入。
相同 72-D 布局仅表示字段顺序兼容，不说明不同训练域和模型权重可以相互替代。

## Actor 输出到位置命令的转换

输出7维是归一化 QVEL 意图，七关节顺序与输入相同；不直接代表 rad、Nm 或 RMP最终输出位置。
这些保存配置的动作转换为：

```text
mu = Actor(obs)                           # 原始线性输出，可超出[-1,1]
a = clip(mu, -1, 1)
v_nominal = a * deg2rad([210,210,240,240,300,300,300])
(q_ref_next, v_executed) = CartesianProject(q_ref, q_measured, v_nominal, dt=0.005)
previous_action_next = clip(v_executed / velocity_limit_rad_s, -1, 1)
simulated_RMP_input = q_ref_next           # rad，保持为策略侧位置参考
```

速度上限的 rad/s 值约为 `[3.665191,3.665191,4.188790,4.188790,5.235988,5.235988,5.235988]`。
`action_velocity_scale=1`，动作低通时间常数为0，动作 jerk filter 为0，anti-windup 关闭。
投影内部以持久 q_ref 的 FK/Jacobian 计算可行速度，同时约束 XML 关节位置限位、速度限位、
`abs(q_ref_next-q_measured)<=velocity_limit*10s` 及笛卡尔位置/roll/pitch 集合。
候选更新为 `q_ref + v_projected*0.005`；若线性可行性或实际非线性 FK 检查不通过，保持原 q_ref，
回填执行速度为零。这不是每 tick 从 measured q 重新施加静态 lead 的控制式。

投影迭代24次，容差 `2e-5`，位置/姿态 CBF gain 均为20 s^-1，位置 margin 为0.5 mm，姿态 margin 为0.1度。
V223 的位置集合为 X[-0.348,0.348]、Y[-0.700,-0.280]、Z[1.00,1.15] m；
其他五个模型为 X[-0.145,0.145]、Y[-0.595,-0.355]、Z[1.00,1.15] m。
所有模型 roll/pitch 均限制为相对注册参考姿态的正负2度。
配置中的加速度上限 `[1300,1300,1800,3000,3000,3000,3000] deg/s^2` 不改变此动作定义；
本分支直接形成位置参考，RMP生成后续运动，不能据此给 Actor 再套一个 QACC 积分器。

仿真链为 Actor -> 限幅/持续参考与笛卡尔投影 -> recovered RMP -> 仿真输出延迟/XML PD -> MJX。
机器人侧边界应是策略 q_ref -> 既有安全与单位适配 -> `MechUnitCmd.jnt_pos` -> 机器人已有 RMP。
仿真 RMP 的最终 `command_q` 不是 Actor 的输出，recovered RMP、XML PD 和仿真延迟也不在机器人上叠加。

## Reset、时间状态和运行时复现要求

网络是前馈 MLP，完整控制接口仍有跨 tick 状态：持续 q_ref、投影后 previous_action、8槽球历史与 age，
V224 还有41槽前缀历史及可用 lag 计数。reset 从初始化的 measured q 重置 q_ref，previous_action 置零；
8槽球位置用 reset 球观测填充，当前槽 age 使用 reset age，其余槽先置1秒，进入输入时 clip 为1。
V224 的41槽用 reset 前缀填充，但未达到对应 lag 的15维块仍全部为零。

相机无新帧时持有位置，并维护对应源时间戳；每5ms只推进一次策略历史。
这些保存配置没有启用高球预测器或将持有球状态传播到当前时刻的开关，也未要求相机可见/view-bounds才能刷新采样。
真实丢帧、预测、失效、重新接管和安全干预的 q_ref/reset 行为需要单独匹配的运行时合同。
验收时须同时核对字段顺序、坐标和site定义、age/valid、连续历史、投影/回退和输出单位；仅输入维度相同不足以建立兼容性。
本次归档未实现或验收新的实物适配，不通过旧50/57/67-D接口解释这些72/117-D模型。
