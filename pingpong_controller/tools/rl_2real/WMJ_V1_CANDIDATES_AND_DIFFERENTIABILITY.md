# WMJ-V1 候选备案与可微训练要求

2026-11-12 用户恢复任务，并明确以下两项候选和一项必做要求。
主版本继续固定为 WMJ-V1；候选登记不改变现有 checkpoint、CONTACT、EXEC、
物理、观测、奖励或部署合同。实施候选之前仍需实时 QA 确认。

## 候选：60 Hz 球观测与配对历史

- 将球观测更新率从 90 Hz 降至 60 Hz，以较少样本覆盖完整颠球周期。
- 历史仍覆盖已确认的 640 ms，每条球样本配对同一时间戳的球拍位置/姿态。
- 仅为观测候选，不改变 200 Hz 策略、机器人反馈或 1 kHz 物理/控制频率。
- 640 ms 约包含 39 个新球样本；最终槽位数、输入维度和时间抖动余量待设计确认。
- 实施前明确相机实际采样与软件降采样的区别，验证时间戳、龄、掩码、
  AR1 时间相关性、估计器和 checkpoint 兼容性；比较端到端耗时与颠球效果。
- 当前状态：仅备案，未启用；现有 90 Hz、64 个历史槽位、969 维 Actor 保持。

## 候选：隐空间 Actor 与隐空间世界模型

- 若显式输入成为经测量确认的瓶颈，可将 Actor 输入压缩为隐空间向量，
  并让世界模型预测下一隐状态。
- 保留历史对齐、任务目标和必要控制记忆；是否全量编码、隐维数、解码器、
  损失权重及迁移方案均待 QA，不默认指定为 VAE。
- 若实施，必须验证表示一致性、多步预测一致性、物理/任务输出和动作效果，
  防止表示坍缩及信息丢失；Actor 的收益梯度必须穿过潜在动力学。
- 当前状态：仅备案，未启用；结构化物理世界模型保持。

## 必做：可微世界模型与短窗口策略反传

- 世界模型必须支持对连续状态和动作求导，策略通过短窗口想象收益反传学习。
- Actor 更新时冻结世界模型及目标 Critic 的参数，保留它们对状态/动作的导数。
- Critic 回归目标停止梯度；不跨物理 reset 或不同反传窗口反传；前向状态连续。
- 现有 JAX 路径是分段可微实现。接触切换、clip、投影、事件和失败掩码存在
  非光滑边界；可运行 autodiff 不等于梯度可靠。固定模式需检查有限差分，
  模式变化需检查扰动收益/动作效果，不宣称全局光滑或长窗口已通过。
- 不以截断全部动力学梯度或改为纯模型内 PPO 来替代此必做要求。
  自定义 VJP、平滑代理等改动须先 QA，并验证前向物理合同。
- 加速需实测：模型前向、Actor 展开/反向/优化、Critic 更新、采集/拟合/验证
  的完整成本和到达任务验收标准的时间；可微本身不保证加速。
- 当前状态：梯度通路已实现；此前 H64 尾部梯度分歧仍未解决，完整可靠性与
  总达标时间加速尚未验收。本轮 Critic 冻结诊断不提供新的 GPU 梯度合格结论。

方法参考：[SuperMimic 论文 v2](https://arxiv.org/abs/2610.28480v2) 与
[作者项目页](https://supermimic.github.io/)。借鉴的是短想象展开的策略梯度路线，
不将其人形机器人任务的速度倍率当作本项目结果。

## 恢复后的当前阶段

复用 EMA 0.05/0.01 的 Critic 第 1144 步检查点及已有 128 个训练、32 个留出
来源，进行同 H128 窗口的冻结回报/价值对照，并按接触阶段、距失败时间和
目标区域分层。所有网络冻结，不更换默认方案；新输出最多 2 MiB，
总输出额度 6.21875 GiB，磁盘空闲至少 8 GiB。留出来源仅与本轮 Critic 拟合
隔离，早期 u30 的训练曾允许使用整个种子库，不能称为从未见过的最终测试集。
