## 2. 相对 `u6247` 解决的实机 Sim2Real 根因

基于 2026-11-27 实物无风测试录制（`u6247` 固定在第 6–7 拍失败而 `V321` 在同条件下稳定颠球）的逐拍排查与 MJX 闭环复现，本版本通过 **11 阶段零重编译 Sim2Real 自动课程**（`sim2real_r5.py` / `train_sim2real_r5.py`，自 `u6247` 续训 1,200 updates 至 `u7447`）彻底解决了以下 5 类 Sim2Real 差异：

1. **RMP 卡尔曼稳态协方差差异（`P_cold → P_warm`，头号根因）**：
   - 原训练环境复位使用冷协方差 `diag(0.01, 0, 0)`，而实机 `release_gate` 接管前以 200 Hz 保持 `q_reset` 2–5 s，滤波协方差始终处于 200 Hz 稳态 `P_warm`；
   - `u6247` 仅切换 `P_warm` 即从 `100%` 跌至 `0%`（0.81 s / 2 拍）；`u7447` 通过 8 档对数增益均匀保正定凸插值课程（`S00–S07`）将 `100% P_warm` 存活率提升至 **100.00%（1280/1280）**，同时保持 `P_cold` 100% 物理存活。
2. **实机 `+Y` 方向重力/标定坐标系倾角偏移**：
   - 全向注入水平等效重力（含 `+Y` 偏量，覆盖实机实测 `ay ≈ +0.125..+0.145 m/s²`、`az ≈ -9.63..-9.71 m/s²`），补齐原 `wind_y_nonpositive` 缺失 `+Y` 扰动的盲区。
3. **隐藏 mocap 延迟 + 静态 Z 偏置 + 零风噪声假风脉冲**：
   - 在不抬高上报延迟特征 `obs[61:69]` 的前提下注入 `0–20 ms` 隐藏球观测环形缓冲延迟、静态 Z 偏置（覆盖实机 `-12 mm`）及每拍 `0.6/0.6/0.8 mm` mocap 抖动，并实时重算 `obs[114:120]` 风特征（采用真非对称 Actor-Critic，Critic 读取纯净观测）。
4. **接触恢复系数与机械臂 RMP 动力学偏差**：
   - 随机化 `pair_solref` 接触阻尼（覆盖实机 `e_n ≈ 0.58–0.63` 及更软球面）、初始放球 XY 偏置（`±6 mm`）及 RMP `kp/kd` 增益偏差。
5. **抗风能力完整保留**：
   - 在全部实机偏差叠加的同时，完整保留 `wind_y <= 0`、`1.6 m/s` X 轴 `±45°` 锥区恒定风与 Slow OU / Gust 动态风的早/晚起风抗风能力。
