- 归档目录：`pingpong_controller/outputs/rl_sim/v325_wind_early_r5fast_u6247_20261127/`

  - `MANIFEST.json`（完整谱系、依赖编码器 SHA-256 与汇总指标）

## 实机输入输出契约（120 维 Actor + 三层 MLP）

推理只使用 `params['pi']` 的确定性均值输出（部署不使用 `log_std` 或 `params['v']`），输入为 `float32`，无运行均值/方差归一化，且**不包含任何仿真特权风速输入**。

### 1. 网络结构与前向计算

参考实现：`pingpong_controller/outputs/rl_sim/v325_single5_windfeature_high_train_20261124_r1/wind_features.py` 中的 `apply_actor(pi, obs)`。

- 结构：`120 → 282 (tanh) → 282 (tanh) → 282 (tanh) → 7 (linear)`
- 权重键：`pi['l1']` (`[120, 282]`)、`pi['l2']` (`[282, 282]`)、`pi['l3']` (`[282, 282]`)、`pi['out']` (`[282, 7]`)
- 与旧版 V321（`72 → 256 → 256 → 7`）相比，多了一层隐藏层 `l3` 且隐藏宽度为 `282`。
- 为保证零附加特征路径与训练一致，`apply_actor` 在第一层将 `obs[..., :118]` 与 `obs[..., 118:120]` 分块做矩阵乘后按 `any(obs[..., 118:] != 0)` 合并再过 `tanh`（FP32 最高精度）。

### 2. 120 维输入布局（左闭右开）

1. **`0:72` — 原生 V321 72 维观测**（与 `FPLC_V321_S4_U2097_DEPLOYMENT_20261029.md` 完全一致）：
   - `0:7`：实测右臂关节角 `q`（rad，顺序 `RightArm-0` 至 `RightArm-6`）
   - `7:14`：实测关节角速度 `dq`（rad/s）
   - `14:21`：持续积分参考误差 `q_ref - q`（rad）
   - `21:28`：上一周期投影后实际执行的归一化动作（`[-1, 1]`）
   - `28:52`：最近 8 个策略周期（5 ms）的球心 XYZ（m，最新在前）
   - `52:55`：正运动学球拍参考点 XYZ（m）；`55:61`：姿态旋转矩阵前两列（第 0 列 XYZ，第 1 列 XYZ）
   - `61:69`：对应 8 步历史球观测年龄 `clip(age_s / 0.25, 0, 1)`
   - `69:71`：回合目标 XY（m）；`71:72`：球观测有效标志（0/1）

2. **`72:112` — 500 ms 因果球观测历史（40 维）**  
   参考实现：`pingpong_controller/tools/rl_sim/fixed_plane_wind_history.py`（`LAGS = (0, 10, 20, 30, 40, 60, 80, 100)` 步，即 `[0, 50, 100, 150, 200, 300, 400, 500] ms`，保留长度 101 步环形缓存；注意 V325 single5 丢弃了历史后缀末尾 2 维 `bounds_deg / 20`）：
   - `72:96`（24 维）：8 个 lag 时刻球心相对最新球心的位置差 `pos[lag] - pos[0]`（m）；当 `valid[lag]` 或 `valid[0]` 无效时置 0
   - `96:104`（8 维）：8 个 lag 对应的真实相机采样年龄 `clip(age_s / 0.6, 0, 1)`；无效时置 0
   - `104:112`（8 维）：8 个 lag 有效标志（`observed & finite & age_s <= 0.6 s`，0/1）

3. **`112:114` — 第 5 击后因果阶段基函数（2 维）**  
   参考实现：`pingpong_controller/outputs/rl_sim/v325_single5_windfeature_high_train_20261124_r1/single5_runtime.py` 的 `acquisition_features`：
   - 仅依赖实机可观测确认击球计数 `confirmed_hits` 与第 5 次确认击球时刻 `fifth_hit_s`：
     - 未满 5 击时：`progress = 0.0`
     - 第 5 击及之后：`phase = clip((t_s - fifth_hit_s) / 3.0, 0.0, 1.0)`，`progress = sin(0.5 * pi * phase)^2`
   - `112`：`progress`；`113`：`clip(72.0 * progress, 0.0, 1.0)`

4. **`114:118` — 因果空气阻力反推风速估计（4 维）**  
   参考实现：`pingpong_controller/outputs/rl_sim/v325_single5_windfeature_high_train_20261124_r1/observed_force.py` 的 `observed_force_features`：
   - 仅使用 `72:112` 历史球观测（无任何特权真值），基于 4 g 乒乓球二次气动阻力公式（`ρ = 1.2 kg/m³`，`Cd = 0.47`，`r = 0.02 m`）对 6 组连续三点飞行段反推水平风速（仅取 `-11.5 < a_z < -8.5 m/s²` 的自由飞行段，限制 `wind_y <= 0` 与 `|w| <= 1.6 m/s`，经 `select_consistent_wind` 筛选且要求存在 `age >= 0.25 s` 的成熟历史）：
   - `114:116`：`estimated_wind_xy / 1.6`（无效或估计风速 `< 0.05 m/s` 时置 0）
   - `116`：`estimate_age_s / 0.6`（无效时置 `1.0`）
   - `117`：估计有效标志（0/1）

5. **`118:120` — 强风死区特征（2 维）**  
   参考实现：`pingpong_controller/outputs/rl_sim/v325_single5_windfeature_high_train_20261124_r1/wind_features.py` 的 `encode`：
   - `speed_m_s = 1.6 * ||obs[114:116]||_2`
   - `gain = clip((speed_m_s - 1.25) / 0.35, 0.0, 1.0)`（当 `obs[112] > 0`），否则 `0.0`
   - `118:120 = obs[114:116] * gain`

### 3. 控制与投影参数（相对 V321 的关键差异）

- **姿态投影限位**：相对参考姿态的 roll / pitch 限位由 V321 的 `±2.0°` 放宽至 **`±5.0°`**（抗强风所需拍面倾角余量）。
- **其余控制链与 V321 保持一致**：控制周期 `5 ms`，球观测 `90 Hz`，QVEL 关节速度上限 `[210, 210, 240, 240, 300, 300, 300] °/s`，工作空间 `X[-0.348, 0.348]`、`Y[-0.700, -0.280]`、`Z[1.00, 1.15] m`，24 次投影迭代（位置/姿态 CBF 系数 `20 s⁻¹`，位置余量 `0.5 mm`，姿态余量 `0.1°`），实机经既有单位换算和安全限幅下发 `q_ref`。
